01 / Scroll systems

Scroll acts like a camera.

The original principles were expanded into a routing system for native view timelines, sticky narratives, GSAP pinning and scrubbing, horizontal scene changes, media sequences, and mobile-safe alternatives.

Scene 01

Anchor the visual.

A sticky composition holds orientation while copy advances. Each step changes one meaningful state instead of stacking unrelated effects.

Scene 02

Scrub with purpose.

Use GSAP only when native timelines cannot deliver precise pinning, labels, synchronized media, or complex scene choreography.

Scene 03

Recompose mobile.

Mobile becomes stacked scenes or a swipe gallery, not a desktop pin sequence compressed into a narrow viewport.

02 / Momentum carousel

Drag feels physical.

The upgrade adds an Embla decision model, physics-based drag, variable widths, active-slide depth, keyboard controls, reduced-motion handling, and strict rules against hidden autoplay.

MomentumVelocity carries into the landing state instead of stopping at release.
ContinuityShared view transitions preserve identity between gallery and detail.
AccessButtons, focus, labels, and swipe all operate the same content model.
RestraintOne progress-driven treatment per carousel, never a carnival of transforms.

03 / Typography

Type carries the narrative.

Fluid scales, optical sizing, balanced wrapping, variable-font axes, semantic split-text limits, and scroll-linked display treatments replace generic headings.

Kinetic
Hierarchy

Display type uses a controlled optical system: tight leading, size-specific tracking, perceptual color, and a single motion concept. Body copy remains stable and readable.

04 / Shading and material

Depth follows one light.

Random blur and shadows were replaced by a coherent material stack: base fill, ambient gradient, occlusion, directional shadow, specular edge, color spill, and adaptive glass weight.
