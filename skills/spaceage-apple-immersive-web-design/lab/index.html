Running it

Three commands.

npm run setup

Fetches GSAP, Embla and Lenis from npm into lab/vendor/ so every page runs offline.

npm run verify

Drives all pages in headless Chromium and asserts behaviour, accessibility fallbacks and frame pacing. Writes proof/verification.json.

npm run capture

Writes desktop, mobile and reduced-motion screenshots to proof/.
