Kinetic typography

Type is the interface.

Four motion levels — block, line, word, character — and a hard rule about which one a given piece of text is allowed to use.

Level 2 — line motion

Lines rise out of their own mask, because a line is the unit a reader actually tracks.

Built with SplitText's mask: 'lines': each line gets a clipping wrapper, so the text slides out from behind an edge instead of fading in mid-air. autoSplit re-splits on resize and font swap; onSplit rebuilds the tween against the new lines.

Level 3 — word motion

Short statements earn word-level staggering. Paragraphs never do.

The accessible name is preserved: SplitText writes aria-label on the container and hides the fragments, so a screen reader still reads one sentence, not 47 spans.

Level 4 — character motion
Restraint

One word. Character motion is for a logotype or a single hero phrase — never for a sentence, and never below a display size.

Masked reveal — zero JavaScript

A registered custom property drives a gradient mask along a view timeline.

No observer, no scroll handler, no library — and it degrades to fully visible text.

Variable axis on scroll
Weight responds to position.

The axis value is animated, not the font-size — layout never reflows. Requires a variable font to be visible; the interpolation itself runs regardless, which is why the value is asserted rather than the pixels.

Velocity-reactive marquee

Direction follows the reader.

Scroll down and the row runs left; scroll up and it reverses. One wrapped translation drives the whole row — no clones animating independently.
