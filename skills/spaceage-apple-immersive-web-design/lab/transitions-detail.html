Destination

One element, two documents.

The panel above is a different element in a different document. Because both documents give it view-transition-name: hero-media and both opt in with @view-transition, the browser treats them as the same object and morphs between them.

No shared runtime, no client-side router, no framework. It also degrades perfectly: an engine without support performs an ordinary navigation.
