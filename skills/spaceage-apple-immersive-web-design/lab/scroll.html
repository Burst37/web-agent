01 — Reveal

Native first. Library second.

Where animation-timeline: view() exists, this reveal runs entirely on the compositor with no JavaScript. Where it does not, one IntersectionObserver adds .is-visible. Either way the content has a visible resting state, so a script failure can never leave the page blank.

No scroll handler

View timelines are declarative. Nothing runs on the main thread per frame.

Range control

animation-range: entry 8% cover 34% is the whole choreography.

Fail-visible

The hidden state is applied by a class, only after a mechanism is confirmed.

One anchored visual, three advancing states.

05 — Media scrub

Frame-accurate, decoded ahead.

Scroll progress selects a frame; the frame is painted inside a single requestAnimationFrame, never from the scroll event itself. Frames are decoded to ImageBitmap before the sequence is reachable.

frame 0 / 0

In production these are AVIF/WebP files capped by viewport and DPR. Here they are generated at runtime so the lab stays dependency-free and offline — the decode queue, the rAF paint and the progress mapping are the real thing.

Velocity accents ride decorative layers only.
