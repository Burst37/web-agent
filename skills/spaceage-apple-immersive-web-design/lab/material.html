    interpolate-size

    Height to auto, actually animated.

    Before interpolate-size: allow-keywords, auto was not an interpolable value, so every accordion measured scrollHeight and animated a pixel number — then broke whenever the content reflowed. This transitions the keyword itself.

    Fall back to an instant open. A jump is acceptable; a clipped panel is not. calc-size() covers the cases where you need arithmetic on an intrinsic size.
